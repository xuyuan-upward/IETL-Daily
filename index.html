关于英音朗读

朗读支持三种引擎，按「离线 → 云端 → 系统」自动择优，也可在上方手动关闭：

  • 📦 内置离线语音包（推荐）：随项目自带的 Piper 神经语音包（英音/美音 × 男声/女声 共 4 个），在浏览器内本地合成，完全离线、不消耗流量、无需 API Key，音质接近真人。每个语音包首次使用需装载约 60MB 模型（之后缓存在浏览器里）。
  • ☁️ 云端英音：填入 TTS 模型名 + API Key 即可，音质稳定、不受系统语音包限制，朗读失败会自动回退。
  • 💻 浏览器系统语音：使用 Web Speech API，完全本地、无需 Key，音质取决于系统语音包：
    • Chrome / Edge：内置 Google UK English Female/Male，效果最好，推荐。
    • Windows 语音包：设置 → 时间和语言 → 语音 → 添加 English (United Kingdom)，可得到 Microsoft Hazel / Sonia / Ryan。
    • Firefox：依赖系统语音，英音支持较弱。
